INGEST FOLDER
─────────────────────────────────────────────────────
Drop files here to feed context into the content generator.

Supported:
  .txt    Plain text (meeting notes, ideas, emails, proposals)
  .md     Markdown (Notion exports, docs)
  .csv    Data (customer lists, stats, results)
  .json   Structured data

Examples:
  - customer-feedback.txt
  - sales-proposal-v2.txt
  - meeting-notes-june.txt
  - product-update.md

The generator (generate.js) reads ALL files in this folder
and uses them to make generated content more specific and
grounded in real Eso Es context.

Delete files you no longer want included.
